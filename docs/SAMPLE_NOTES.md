# Sample notes

`sample_notes/` holds fictional notes for a fictional manager at "Kestrel Labs". They are not anyone's real notes. Use them for development, tests and the demo.

## Setup (after cloning or pulling)

Git doesn't keep file dates, and some files are generated by a script. Run this once:

1. `python3 -m venv /tmp/gen && /tmp/gen/bin/pip install pymupdf python-docx`
2. `/tmp/gen/bin/python scripts/make_sample_notes.py`

This creates the .docx, .pdf and .png files, the symlinks and the file dates. You can run it again at any time.

## The demo moment

**Ask:** "What did we decide about the analytics vendor for Lighthouse, and has it changed?"

**A good answer:**
- 22 Sep: decided on **Corvid**, with beta on 3 Nov (`meetings/2026-09-22 …`)
- 6 Oct: legal found that Corvid keeps data in the US only, which is a problem for the two pilots that need UK hosting (`1on1s/2026-10-06 …`)
- 20 Oct: **switched to Ledgerly**, beta moved to 17 Nov. The older decision is replaced (`meetings/2026-10-20 …`)
- 10–12 Nov: beta slipped again to **24 Nov** (`inbox/2026-11-12 quick note.txt`, plus the Slack screenshot)
- Show a "superseded" badge on the 22 Sep note

## Edge cases (`sample_notes/edge_cases/`)

| File | Tests | Expected behaviour |
|---|---|---|
| `.env`, `.ssh/config` | Denylist (fake contents) | Never read. Logged as blocked |
| `escape link.md` → `../../README.md` | Symlink pointing outside the granted folder | Blocked by `resolve_and_check` |
| `loop` → `..` | Symlink loop | The folder walk finishes and doesn't loop forever |
| `injection_test.md` | Injection styles: HTML comment, fake "SYSTEM", URL fetch, fake closing tag | Treated as data. No tool calls, no fetch |
| `empty.md`, `whitespace_only.txt` | Nothing to index | Skipped without errors |
| `corrupt.pdf` | Broken file | Skipped, error logged, the rest of the indexing continues |
| `password protected.pdf` | Encrypted | Skipped with a clear reason |
| `scanned receipt.pdf` | Image only, no text layer | Zero text. Later: OCR |
| `meeting recording.m4a`, `budget_export.csv` | Types we don't support | Ignored |
| `latin1 windows.txt` | Not UTF-8, CRLF line endings | Read without crashing (fallback decoding) |
| `cyfarfod tîm ☕.md` | Unicode file name, Welsh accents (ŵ ŷ), CJK, emoji, £€¥ | Indexed and searchable |
| `NOTES.MD` | Upper-case file extension | Read as Markdown |
| `no date note.txt` | No date in the name or text | Falls back to the file's modified time |
| `a/b/c/d/deep note.md` | Deeply nested folders | Found |
| `long standup log.md` | ~110 KB, one decision buried in the middle | Chunked. "What is the beta called in customer comms?" → "Lighthouse Preview" |
| `Copy of 2026-09-22 …md` | Duplicate with a newer file date | Same hash as the original. It must not count as "newer" and replace the original |

## Rules for adding notes
- Fictional people and companies only. Use `.example` domains for links.
- Add each new file to the tables above. If it has a date, also add it to `DATES` in `scripts/make_sample_notes.py`.
